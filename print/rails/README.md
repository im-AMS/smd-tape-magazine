# Rails

The magazines stand in a rail. I didn't design one; these are the rails from
the two earlier versions of this magazine, included unmodified so you can
pick whichever you prefer. **They keep their original licenses**, which are
different from the rest of this repo.

## `lord-asdi/`: the original rails

From [SMD Component Tape Magazine (8, 12, 16mm)](https://www.printables.com/model/580643)
by **Lord Asdi**. License: **CC BY 4.0**.

| file | rail length |
|---|---|
| `rail_100mm.stl` | 100 mm |
| `rail_176mm.stl` | 176 mm |
| `rail_300mm.stl` | 300 mm |

This magazine's outline was traced from Lord Asdi's body, so these rails
match its feet.

## `onegeekguy/`: rail with O-ring grip

From [SMD Magazine 8/12/16mm Modified Easy Print](https://www.printables.com/model/1182844)
by **OneGeekGuy**. License: **CC BY-NC 4.0**.

| file | what |
|---|---|
| `railupdated.step` | rail with a groove for an O-ring to grip the magazines; it can be filled with sand or concrete for weight |
| `railcap.step` | end cap for the rail |

Needs an O-ring: R32, 3.4/3.5 mm (per the original listing). Most slicers
open STEP directly.

This rail was designed for OneGeekGuy's remix, whose feet were changed to
9 mm. **I haven't tested it with this magazine.**
